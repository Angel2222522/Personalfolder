# Προσωπικός Φάκελος

Τοπική Android εφαρμογή για ιδιωτική οργάνωση εγγράφων, OCR, υποθέσεων και προθεσμιών.

## Τι περιλαμβάνει

- Εισαγωγή PDF και εικόνων από τη συσκευή, κάμερα και Android share sheet.
- Τοπικό OCR ελληνικών/αγγλικών με προτεινόμενη κατηγορία, φορέα, ημερομηνίες και αριθμό πρωτοκόλλου.
- Αναζήτηση σε τίτλους, ετικέτες, OCR και metadata.
- Υποθέσεις με κατάσταση, συνδεδεμένα έγγραφα, checklist και χρονολόγιο.
- Υπενθυμίσεις λήξης 30/7/0 ημερών με τοπικές ειδοποιήσεις.
- Κοινοποίηση μεμονωμένου εγγράφου, εξαγωγή επιλεγμένων εγγράφων σε ZIP ή ενιαίο PDF.
- Biometric lock, AES-GCM κρυπτογράφηση αρχείων με Android Keystore και password-protected portable backup.

## Αρχές

- Η κανονική λειτουργία είναι offline.
- Δεν υπάρχει backend, λογαριασμός, analytics, διαφημίσεις ή άδεια `INTERNET`.
- Τα αρχεία αποθηκεύονται σε ιδιωτικό χώρο της εφαρμογής και κρυπτογραφούνται με κλειδί Android Keystore.
- Το OCR εκτελείται στη συσκευή με Tesseract και περιλαμβάνει ελληνικό και αγγλικό μοντέλο.
- Το backup είναι κρυπτογραφημένο με κωδικό που δεν αποθηκεύεται από την εφαρμογή.

## Τεχνολογία

Kotlin, Jetpack Compose, Material 3, Room, WorkManager, Android Keystore και Tesseract4Android.

## Build

Απαιτούνται Java 17, Android SDK 36 και Gradle 8.11.1 ή Android Studio που υποστηρίζει το project.

```bash
gradle testDebugUnitTest
gradle lintDebug
gradle assembleDebug
```

Το debug APK παράγεται στο `app/build/outputs/apk/debug/`.

## Περιορισμοί v1

- Η εισαγωγή πολλών εικόνων ομαδοποιεί τις εικόνες σε ένα έγγραφο. Η πλήρης επεξεργασία περιγράμματος/προοπτικής scanner θα προστεθεί σε επόμενη έκδοση.
- Τα προτεινόμενα στοιχεία OCR είναι ενδείξεις και χρειάζονται έλεγχο από τον χρήστη.
- Οι υπενθυμίσεις εξαρτώνται από τις ρυθμίσεις εξοικονόμησης μπαταρίας της συσκευής.

## Απόρρητο

Δεν πρέπει να προστεθούν πραγματικά προσωπικά έγγραφα, κλειδιά υπογραφής ή credentials στο repository.

Το ZIP/PDF export είναι σκόπιμα απλή εξαγωγή για κοινοποίηση και δεν είναι κρυπτογραφημένο. Για μεταφορά προσωπικών δεδομένων χρησιμοποίησε το password-protected backup.
