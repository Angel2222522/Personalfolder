# Έρευνα παλινδρόμησης OCR

Το αρχείο αυτό είναι το μόνιμο ημερολόγιο της έρευνας. Ενημερώνεται μόνο με
ελεγμένα στοιχεία. Δεν αντικαθιστά τα Git commits: κάθε αλλαγή κώδικα πρέπει να
έχει δικό της μικρό commit και εδώ να αναφέρεται η αιτία και η επαλήθευσή της.

## Κανόνας καταγραφής

Για κάθε εύρημα καταγράφονται:

1. το σύμπτωμα,
2. η ακριβής θέση στον κώδικα ή στο ιστορικό,
3. το στοιχείο που το αποδεικνύει,
4. η ελάχιστη αλλαγή που έγινε,
5. η παλιά συμπεριφορά που πρέπει να παραμείνει,
6. ο έλεγχος που εκτελέστηκε,
7. όσα δεν έχουν ακόμη επαληθευτεί σε πραγματική συσκευή.

Δεν θεωρούμε ότι μια λειτουργία δουλεύει μόνο επειδή ο κώδικας μεταγλωττίζεται.

## Κύριο επιβεβαιωμένο εύρημα

Η αποτυχία του OCR δεν προκλήθηκε από αλλαγή των πακέτων της αναμόρφωσης.
Τα αρχεία γλωσσικών μοντέλων ήταν ήδη κατεστραμμένα πριν από την αναμόρφωση.
Η αναμόρφωση τα μετέφερε χωρίς να διορθώσει την εγκυρότητά τους και ο παλιός
έλεγχος τα δεχόταν επειδή έλεγχε μόνο ένα μικρό ελάχιστο μέγεθος.

## Διαδρομή που ελέγχθηκε

Η βασική ροή που εξετάστηκε είναι:

`URI αρχείου → import → κρυπτογράφηση → Room → WorkManager → OcrWorker →`
`προσωρινή αποκρυπτογράφηση → PDF/εικόνα → Tesseract → metadata → Room → UI`

Ελέγχθηκαν στον κώδικα:

- το document ID και το `WorkManager` input,
- η μοναδική εργασία OCR ανά document,
- η σειρά των locks και των Mutex,
- η διαδρομή `filesDir/documents/<document-id>/page_<n>.pf`,
- η ταξινόμηση PDF και εικόνας,
- η απόδοση σελίδων PDF,
- η εγκατάσταση των μοντέλων Tesseract,
- οι καταστάσεις processing και τα retries,
- η επανεκκίνηση εκκρεμών εργασιών κατά την εκκίνηση.

Δεν βρέθηκε τεκμηριωμένος κύκλος lock inversion στη σημερινή ροή. Η εισαγωγή
κρατά το κλείδωμα μόνο για τις δικές της ενέργειες και δεν περιμένει να
ολοκληρωθεί το OCR.

## Τι δεν έχει αποδειχθεί ακόμη

Στο παρόν περιβάλλον δεν υπάρχουν Android SDK, Gradle wrapper, `adb` ή φυσική
συσκευή. Το Android runtime επαληθεύτηκε μέσω GitHub Actions emulator, όχι σε
φυσικό τηλέφωνο. Δεν έχει επαληθευτεί:

- εγκατάσταση του APK ως ενημέρωση της παλιάς release εφαρμογής,
- η μόνιμη release υπογραφή στο τελικό APK,
- OCR σε πραγματικές φωτογραφίες/έγγραφα του χρήστη και όχι στα ελεγχόμενα
  fixtures των tests.

Δεν παρουσιάζεται compilation ως απόδειξη λειτουργίας· η λειτουργία που
καλύπτουν τα tests επιβεβαιώθηκε με Android runtime.

## Τι πρέπει να παραμείνει ίδιο

- το `applicationId`,
- οι υπάρχουσες διαδρομές αποθήκευσης,
- τα document identifiers,
- το encryption format και το key alias,
- η βάση και οι υπάρχουσες migrations,
- η λογική διάσπαση UI, persistence, processing, OCR και filesystem,
- οι διορθώσεις ασφάλειας και concurrency που δεν αποδείχθηκαν αιτία.

Δεν έγινε destructive migration, διαγραφή δεδομένων, αλλαγή identifiers,
αλλαγή encryption assumptions ή τυφλό rollback.

Για τη συγκεκριμένη παράδοση ο χρήστης ενέκρινε ρητά εξαίρεση από τη συνέχεια
της προηγούμενης εγκατάστασης, μόνο για να παραλάβει γρηγορότερα APK. Το APK
είναι debug/standalone (`com.angel.personalfolder.debug`) και δεν παρουσιάζεται
ως ενημέρωση της release εφαρμογής (`com.angel.personalfolder`). Η εξαίρεση δεν
αλλάζει τις release continuity απαιτήσεις του project για επόμενες κανονικές
εκδόσεις.
